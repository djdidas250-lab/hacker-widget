Overview

Hacker Widget – Matrix Dual Widgets brings a futuristic cyber-inspired interface to your Android home screen with two interactive widgets packaged together in one APK.

The project combines an animated Matrix-style virtual command interface with a practical digital clock and weather widget.

Features

1. Matrix Virtual Command Hub

- Animated, randomized terminal windows and virtual command panels.
- Matrix-inspired green terminal styling.
- Gunmetal header design.
- Semi-transparent dark widget background.
- Interactive header shortcut to Android system Settings.
- Gear icon for widget configuration.
- Tap-to-refresh functionality.
- Animated transitions and a futuristic interface.
- Encrypted-channel-inspired footer display.

2. Digital Clock & Weather

- Digital clock display.
- Weather information.
- Alarm shortcut.
- Widget configuration options.
- Refresh functionality.

Design & Interface

The visual design combines a dark cyber-inspired appearance with bright Matrix-green terminal elements.

The Matrix Virtual Command Hub is designed to look like a live virtual command environment, while the Digital Clock & Weather widget provides useful everyday information directly on the home screen.

Installation

1. Download the latest APK from the "GitHub Releases page" (https://github.com/djdidas250-lab/hacker-widget/releases).
2. Open the downloaded APK on your Android device.
3. Allow installation from your browser or file manager if Android requests permission.
4. Complete the installation.
5. Long-press your Android home screen and open the Widgets menu.
6. Find Hacker Widget and add either widget to your home screen.
